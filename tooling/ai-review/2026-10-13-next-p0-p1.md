# Next.js P0/P1 本地实施复核

日期：2026-10-13。目标基线：`6d1ef4c4ca86fe3d3719955ff7b10c24bf632fb7`。范围为该 HEAD 上的未提交工作树；开始时已有 AGENTS、ARCHITECTURE、ROADMAP、SEO 及未跟踪的重构计划，均予保留。没有提交、推送、发布、生产平台验收或独立教学审阅。

## 交付范围

按计划建议完成首个 P0/P1 包。`frontend/app` 为多根 App Router，英文旧路径与 zh/ja 前缀不变，初始 HTML 有正确 lang。Next 16.4.0 精确固定到 lockfile；只新增本地迁移命令，默认 Vite/dist 和同一 Worker 的正式配置仍保留。

`apps/web/next` 的 Home、Lesson、Experiment 与元信息在构建侧运行。完整内容集合禁止客户端导入；首页只传当前语言卡片和搜索字段，不传讲解正文。静态讲解保留七章、核心答案和引用；正文仍可能出现在该页面的 RSC 数据中。只有单摆接入交互；其他两个案例在原型中仅保留静态说明，不能将此包视为完整迁移。

Simulation 新增最小 RuntimeLabConfig 支持，旧 Lab 暂时兼容；科学模型、步长和版本没有改动。语言交接保存完整快照及 playing，校验案例/版本、导航目标、标识、大小和有效期；消费一次性导航记录后清理，短期会话记录保留用于历史返回。刷新与直接访问不恢复旧状态。存储禁用时模型仍可使用，语言切换失败给出反馈并留在原页。

BFCache 实测发现 Chrome 在 pageshow 回调中暂时返回旧 Storage 视图；修复为下一任务恢复，并在恢复期间禁用控件。BFCache 命中测试显式移除 Chrome 的禁用参数并确认 pageshow.persisted；普通测试使用默认禁用 BFCache 的 Chrome，覆盖另一条恢复路径。语言选择器返回旧页面后重新启用。

导出后只将 zh.html/ja.html 整理为各目录 index.html，RSC 与 segment 文件保留原路径。三个语言 404 使用共用 MissingBody，实际状态码由 Workers 返回。`/_next/static/*` 长缓存；RSC/HTML 不设置 immutable。原型强制 noindex 且无 sitemap，正式索引策略不变。

## 实验室加载对照与限制

P0/P1 测量驱动同用 Node 24.21.0、Chrome 155.0.8059.40、M1 Pro、390×844、DPR=1、4× CPU、150 ms RTT、1.6 Mbps 下载、冷浏览器缓存，每页 5 次。构建兼容性另用固定 Node 24.11.1 验证。以下为本地 Workers 实验室数据，不能当作生产或真实用户 CWV。

| 页面与指标，中位数 | 原 Vite | Next P1 |
| --- | ---: | ---: |
| 首页 LCP | 496 ms | 484 ms |
| 首页控件可见上界 | 1236 ms | 1656 ms |
| 首页资源中的 JS encodedBodySize 合计 | 97.22 KB | 146.60 KB |
| 单摆 LCP | 408 ms | 572 ms |
| 单摆控件可见上界 | 2513 ms | 2418 ms |
| 单摆真正控制就绪标记 | 未埋点 | 2416 ms |
| 单摆资源中的 JS encodedBodySize 合计 | 220.96 KB | 262.30 KB |

资源合计不含主文档、HTTP 头；KB 为十进制，压缩由本地服务器决定。旧版控件可见指标在 load 后采样，只是上界，不等于实际可交互时间；Next 标记在会话校验/恢复、时钟启动与控件启用的 React 提交后记录。单摆 CLS 中位数为 0，但保留了两个非零样本。P0 地球示意画面观察就绪中位数为 5553 ms，这仍不是精确首帧/纹理解码标记；P1 地球未接入，不作改善宣称。

英文到日文的完整文档切换 5 次测量中位数约 559 ms，包含自动化选择动作到目标完整状态恢复；每次新建源上下文，目标允许复用缓存资源。状态保持通过，仍比原 History API 的语言切换多一次文档导航。原始结果在 `test-results-next-performance/mobile.json` 与 navigation.json。

Next 已拆掉首页全文，但新增框架成本超过当前三个案例的文本节省：JS 传输增加，单摆控制就绪仍超过 2 秒预算。P1 路由/状态原型门槛通过，可继续 P2/P3；P4 需要继续分离模型/读数/场景、处理公式及框架成本，再按同条件复测。未完成的预算不能视为生产切换已获验收。

没有测试实体手机持续动画、100 次参数响应 P95、真实用户 CWV、完整辅助技术或地域网络；Next 开发 Strict Mode 的重复挂载尚未独立验收。导航失败覆盖目标请求预检，预检之后的网络断开仍需 P4 故障恢复验证。模块/纹理/WebGL 的 Next 故障矩阵留待 P3；旧 Vite 相关回归已通过。尚未全面复测预览分支、长期旧 chunk 和所有生产上线项目。
