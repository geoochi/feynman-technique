# Feynman 视觉规范

更新日期：2026-10-11。用途：定义项目的视觉语言、组件尺度与验收方式。

## 1. 规范状态

本规范整理前期视觉研究所得的布局、颜色与字体参数，作为 Feynman 的设计基线。尺寸均为 CSS 像素；首期目录及三个暖纸浅色实验页已实现，实际测试范围见 [本地开发](DEVELOPMENT.md)。电学工作台仍待实施，参数需要在真实页面、多断点和交互状态下验证。

页面结构以经过确认的设计和实际画面为准。仅有某个标题样式或 HTML 元素，不代表它应出现在最终可见布局中。视觉验收须同时记录环境和页面状态。

网站默认英语，顶部用一个语言下拉框选择 English / 中文 / 日本語，保留键盘操作与可见焦点。三语言共用布局，按实际标签长度自然换行；手机顶部可分行，语言入口须完整可见。日语优先使用系统日文字体；科学变量、单位和数值含义共用，切换语言不改变实验状态。分别检查英文长标签、日文排版和中文回归，避免缺字、裁切或水平溢出。

## 2. 视觉语言

目录首页呈现“科学仪器目录”的感觉：浅蓝灰网格纸、细边框、切角卡片、少量发光状态点，图示优先于装饰照片。卡片包含学科、示意图、标题、简述、知识点和进入实验入口。

当前数学、单摆与地球昼夜统一使用暖纸色与琥珀；地球的昼夜明暗只在模型上表现，页面、封面与无 WebGL 示意图均使用浅色背景。电学仍计划用深色仪表盘。统一组件语义与布局槽位，以主题和布局变体匹配案例需要。

当前仓库按维护者授权公开，目录、讲解与实验导航提供 GitHub 入口；首页以三语言投稿区鼓励 Issue 提案和 PR 贡献。卡片页脚仅显示版本，不显示个人作者。讲解页保留科学依据、模型限制及教学审阅状态，素材归属与第三方法定版权记录继续保留。

## 4. 实验主题与布局

| 主题 | 基础颜色 | 布局基线 |
|---|---|---|
| 电学 / `instrument` | 背景 `#03060a`，面板 `#0a1119`，文字 `#e2eaf3`，青 `#3fd8ff`，橙 `#ffb23e`，绿 `#3cf2a3` | Header 60px；左侧 218px；右侧 306px；下方数据区 258px |
| 数学、单摆、地球昼夜 / `paper` | 背景 `#f6f4ef`，纸面 `#fffefb`，文字 `#2a302e`，墨色 `#1d2321`；琥珀 `#c9800f`，蓝 `#2f6fd0` | 共享实验布局：介绍、主图、右侧控制与读数 |

实验标题使用 Noto Serif SC / 系统宋体，仪表数字保留等宽。地球页与其他两个实验共用 paper 主题，地轴、太阳光与标签使用琥珀色，观察点保留蓝色。

地球场景使用正交视图，按画布宽高取景，同时容纳地球与三条太阳光箭头。箭头等长、平行、等距，末端在垂直于光线的同一线上；整体随赤纬旋转，不能只改变光线方向却保留竖直排列。手机也须完整显示箭头，不在画布边缘裁断。

地球按地表经度的东向自转：从北极上方看为逆时针。地轴北端上方放置同方向的弧形箭头，不能随地球贴图一起旋转；晨昏时观察点的当地东方应分别朝向、背向太阳，保证太阳东升西落。

地表使用本地 NASA Blue Marble 卫星合成贴图，展示真实海岸线和地表颜色；昼夜明暗独立计算，不烘焙在贴图内，不使用虚构程序化陆地。保留小字素材署名，避免经纬网遮住地貌；封面与无 WebGL 回退仍为静态示意。

首期三个实验采用以主图为中心的布局（2026-10-11 用户确认的新方向）：

- 桌面从左到右：介绍栏、弹性主图、右侧栏（上方实验控制框，下方公式与读数框）。介绍集中标题、简介与 1–3 个可通过参数探索、以问号结尾的问题。实验页移除学习目标与适用条件、检验理解、依据与来源区块，完整讲解与来源数据保留。取消七步“探究路径”和上一页/下一页；完整七章讲解仍在独立笔记页。
- 1440px 宽时介绍栏 220px，右侧栏 264px；工作区内边距 24px，列间距 18px。≥1920px 时介绍栏 / 右侧栏分别为 260/286px，间距 24px。其余宽度分配给主图，随窗口高度伸展。
- 公式用 KaTeX，相关读数为紧凑矩形，与公式同处一个框；单摆只显示小角度近似周期。参数名称按当前语言显示，后用括号标注公式变量，例如“水平平移（h）”“摆长（L）”。动态案例的播放/暂停、单步、重置、模拟时间与所有参数在右侧同一框；二次函数只保留参数控制与重置参数，不显示播放区、时间、暂停状态或扫描采样点。参数标题旁提供“重置参数”，恢复默认值并暂停，不显示成功提示；播放区重置保留当前参数，回到初始状态并暂停。移除快速探索下拉框、播放速度、视角缩放和状态导入导出；播放固定为 1×。主图底部只有一条简短声明，图例并入这条声明。
- ≤1180px 时收窄侧栏，读数始终跟随控制框下方；≤900px 时介绍移到工作区之后；≤640px 时依次为主图、控制、读数、介绍。手机读数横排，按钮至少 44px 高。
- 单摆在相同视口下采用固定长度比例尺，覆盖 0.2–3 m，改变摆长时图上绳长按同一比例变化，显示米刻度。禁止按当前摆长自动缩放抵消视觉变化；所有模型、时间和参数仍由原运行时管理。

“重置”和“重置参数”均不显示操作成功提示。

电学工作台尚未实现，未来可按元件栏、画布、数据区和属性抽屉组织；不把未来工作台强制套进现有布局。

建议用语义化 token，避免把颜色名当成用途：

```css
/* 项目建议接口；下面是首页主题的参考数值。 */
[data-theme="catalog"] {
  --color-background: #eef2f7;
  --color-surface: #ffffff;
  --color-text: #12202f;
  --color-text-muted: #5b6b7d;
  --color-accent: #0092c7;
  --color-border: rgba(30, 80, 140, .14);
  --card-cut: 12px;
  --page-grid-size: 24px;
}
```

`LabShell` 决定布局，`data-theme` 决定视觉。主题变量限定在对应容器，避免全局 `:root` 规则在单页路由切换后互相影响。

## 5. 组件清单

| 组件 | 必须覆盖的状态 |
|---|---|
| `CatalogHeader` | 桌面/手机、语言选择、键盘焦点 |
| `SubjectFilter` | 全部/选中/hover/focus、数量、窄屏换行 |
| `LabCard` | 默认/hover/focus、长标题、缺图、待发布 |
| `LessonShell` | 1–3 个问题/主图/右侧控制与读数框、全屏、窄屏重排 |
| `WorkbenchShell` | 元件选择、属性抽屉、数据区展开/收起 |
| `ParameterControl` | slider + 数字输入、单位、边界/错误、重置 |
| `PlaybackBar` | 动态案例的播放/暂停/单步、时间、重置；二次函数不显示 |
| `ExplanationPanel` | 1–3 个有价值的问题、完整笔记入口 |
| `RuntimeStatus` | 加载、资源错误、WebGL 不可用、重试 |

设计新增要求：键盘可操作、焦点可见、信息不只靠颜色表达；触屏点击目标建议至少 44px，可扩大透明点击区而不改变参考按钮外观。支持减少动效偏好，教学动画仍提供显式播放。

## 6. 像素级验收协议

“像素级”必须绑定页面、状态和环境；仅比较首页一张截图不够。

1. 建立参考矩阵：首页、数学课程、地球课程、电学工作台；每页列出初始、展开介绍、参数改变、暂停、全屏、窄屏等状态。第一版只承诺已列入矩阵的状态。
2. 建议视口为 1440×900、1920×1080、768×1024、390×844；在相同浏览器版本、OS、DPR、缩放、语言、主题下分别采集参考与本地画面。默认使用英语，同时检查中文与日文排版。
3. 等待字体和纹理完成；固定随机种子、模拟时间、相机位置与实验参数。动态区域提供可暂停帧或固定时钟；无法稳定捕获的区域单独按构图和交互验收，不虚构逐像素一致。
4. 分开比较 DOM 界面与 3D 画布：界面使用截图差分和几何尺寸；画布同时验证相机、投影、几何、光照、色彩空间、阴影、抗锯齿和材质。GPU 差异不能只靠 CSS 修复。
5. 建议首期门槛：关键布局偏差 ≤2 CSS px；固定环境下 DOM 区域差异像素比 ≤0.5%，像素颜色阈值先设为 0.15，实测后冻结。只允许预先列明的动态遮罩；不能通过扩大遮罩隐藏缺失组件。
6. 差异超阈值时人工看 overlay；基线变更必须说明原因。截图一致也不代表公式、交互和键盘操作正确，它们独立验收。

Playwright 支持页面截图比较，官方也说明环境差异会影响图像结果。本项目必须固定执行环境后再使用数值门槛。[Playwright 视觉比较](https://playwright.dev/docs/test-snapshots)

## 7. 实现顺序

先实现字体、token、容器与网格，再做卡片、课程壳和控件，最后校准场景与动效。每个案例按“形状 → 相机 → 材质 → 光照 → 动画 → 标签”的顺序校准。

需要自有实现的资产包括品牌标识、封面矢量图、3D 模型、纹理、讲解与题目。素材保留作者、来源和许可证记录，使用自有或获许可的素材。

首期浏览器测试保存目录和三个实验的桌面/手机截图，用于人工检查而非已冻结的像素对比基线。Chakra Petch 与 JetBrains Mono 通过 @fontsource 自托管，中文使用系统字体回退；中文字体、OS 和 GPU 差异仍会影响画面。尚待补齐：完整状态矩阵、母语文案审校、独立视觉参考、像素差分门槛与触摸设备实测。没有已确认外部参考图时不宣称像素级一致。
