# 待开发实验清单

更新：2026-10-13。依据 [长期路线图](ROADMAP.md)及维护者确认记录的候选列表整理。

当前已有十二个案例：基础四例（二次函数、导数与切线、单摆、地球昼夜）不计入以下待开发项；01–04（波的叠加、弹簧振子、凸透镜成像、纬度与昼长）与 05、06、09、10（积分与面积、单位圆与正弦波、驻波、折射与全反射）已于 2026-10-13 实施并上线，状态见各条目。本文记录选题与建议顺序，不代表全部已立项或承诺发布日期。现有实验的反馈修复、教学审阅与真实设备验证同步推进。

## 使用方式

- 每项初始状态均为“候选”。实施时在对应条目下补充状态：候选 → 本轮选定 → 实施 → 验证 → 已上线 → 用户反馈。
- 完成开发、相称工程验证及正式上线验收后才勾选，并附源码 commit、部署版本和验收记录链接；独立教学审阅与用户反馈另外记录，不因勾选而自动视为通过。
- “路线图已有”与“新增建议”区分原规划和后续细化。顺序可根据学习联系、实际反馈与维护能力调整。

## 第一批：近期优先

目标：在现有四个基础案例上，逐步形成约八个有联系的实验。第一批 01–04 已于 2026-10-13 上线，达成该目标。建议先做波的叠加，再做弹簧振子。

- [x] **01 · 波的叠加与干涉**
  - 核心问题：两列波为什么会加强或抵消？
  - 首版范围：限定一维线性波模型，调整振幅、波长与相位，对照两列波及合成波；明确传播方向与边界假设。
  - 验证重点：同相加强、等幅反相抵消、零振幅边界；区分瞬时位移图像与能量解释。
  - 规划来源：路线图已有候选“波的叠加”。
  - 状态：已上线（2026-10-13）。源码 `frontend/examples/physics/wave-superposition`，合并提交 `3a45196`，部署版本 `f911d736-cf0b-44aa-8167-7b58a1bf2c88`。工程验证：`generate` 注册 8 个案例、`typecheck`、模型单测 11 项、`build` 54 页、Playwright e2e 全绿。案例状态仍为 experimental，独立教学审阅未完成。

- [x] **02 · 弹簧振子与周期**
  - 核心问题：质量和弹簧硬度怎样影响周期？
  - 首版范围：理想无阻尼水平弹簧振子，调整质量、劲度系数与初始位移，观察运动及动能、势能转换，与单摆建立学习联系。
  - 验证重点：解析周期、能量守恒、平衡位置和振幅关系；明确胡克定律适用假设。
  - 规划来源：路线图“振动与周期”的具体化。
  - 状态：已上线（2026-10-13）。源码 `frontend/examples/physics/spring-oscillator`，合并提交 `3a45196`，部署版本 `f911d736-cf0b-44aa-8167-7b58a1bf2c88`。工程验证：`generate` 注册 8 个案例、`typecheck`、模型单测 6 项、`build` 54 页、Playwright e2e 全绿。案例状态仍为 experimental，独立教学审阅未完成。

- [x] **03 · 凸透镜成像**
  - 核心问题：物体靠近透镜时，像的位置和性质为什么会改变？
  - 首版范围：薄凸透镜与近轴光线，调整物距、焦距，观察光路、放大率、实像与虚像。
  - 验证重点：物体在两倍焦距、焦点内外及焦点处的特殊情况；不把无穷远像绘制成有限像。
  - 规划来源：路线图已有候选“透镜成像”。
  - 状态：已上线（2026-10-13）。源码 `frontend/examples/physics/thin-lens`，合并提交 `3a45196`，部署版本 `f911d736-cf0b-44aa-8167-7b58a1bf2c88`。工程验证：`generate` 注册 8 个案例、`typecheck`、模型单测 10 项、`build` 54 页、Playwright e2e 全绿。`u = f` 时模型返回无穷远像、绘图只画平行出射光。案例状态仍为 experimental，独立教学审阅未完成。

- [x] **04 · 纬度与昼长**
  - 核心问题：同一天不同纬度的白昼长度为什么不同？
  - 首版范围：调整纬度、太阳赤纬，对照昼长曲线与极昼极夜边界；沿用现有地球模型的假设，不声称实现轨道或实时天气。
  - 验证重点：赤道、春秋分、极昼极夜和极点退化情形；明确太阳视大小与大气折射是否忽略。
  - 规划来源：路线图已有候选“日照与纬度延伸”。立项前确认独立教学价值；若与现有昼夜页重复，优先完善现有页并记录合并决定。
  - 立项判断：与昼夜页不重复——昼夜页用三维地球解释昼夜成因（定性），本页给出昼长随纬度变化的定量曲线与极昼极夜边界，共用 `cos H₀ = −tan φ tan δ`。判断记录在 manifest 的 modelAssumptions 与 ATTRIBUTION.md。
  - 状态：已上线（2026-10-13）。源码 `frontend/examples/geography/daylight-latitude`，合并提交 `3a45196`，部署版本 `f911d736-cf0b-44aa-8167-7b58a1bf2c88`。工程验证：`generate` 注册 8 个案例、`typecheck`、模型单测 13 项、`build` 54 页、Playwright e2e 全绿。忽略太阳视大小与大气折射。案例状态仍为 experimental，独立教学审阅未完成。

## 第二批：补齐数学、振动与波的学习联系

以下均为沿长期方向提出的新增建议，依据第一批反馈逐项选择，不作为必须全部完成的数量目标。其中 05、06、09、10 已于 2026-10-13 上线。

- [x] **05 · 积分与面积累积**
  - 核心问题：小矩形面积之和怎样逼近曲线下的面积？
  - 首版范围：选定有解析积分的明确函数，调整积分区间、分割数量与取样方式，比较矩形和与精确值。
  - 验证重点：收敛、零长度区间、取样误差；若允许跨越横轴，区分有符号积分与几何面积。
  - 学习联系：承接导数与切线。
  - 状态：已上线（2026-10-13）。源码 `frontend/examples/math/integral-area`（f(x)=x²，参数 a、b、n、取样位置 s），合并提交 `0bfe35e`，部署版本 `4fb6828e-139f-4c52-8c5c-622f85541ef2`。工程验证：`generate` 注册 12 个案例、`typecheck`、模型单测 9 项、`build` 78 页、Playwright e2e 全绿（含本案例回归测试）。案例状态仍为 experimental，独立教学审阅未完成。

- [x] **06 · 单位圆与正弦波**
  - 核心问题：圆周运动怎样生成正弦曲线？
  - 首版范围：从半径为 1 的单位圆出发，再允许调整半径、角速度与初相位，关联圆上投影和时间波形；半径改变后明确标为一般圆。
  - 验证重点：关键相位、周期、振幅、角度单位与转动方向。
  - 学习联系：连接三角函数、弹簧振子与波。
  - 状态：已上线（2026-10-13）。源码 `frontend/examples/math/unit-circle-sine`（参数半径 R、角速度 ω、初相位 φ₀），合并提交 `0bfe35e`，部署版本 `4fb6828e-139f-4c52-8c5c-622f85541ef2`。工程验证：`generate` 注册 12 个案例、`typecheck`、模型单测 17 项、`build` 78 页、Playwright e2e 全绿（含本案例回归测试）。半径不为 1 时标注为一般圆。案例状态仍为 experimental，独立教学审阅未完成。

- [ ] **07 · 阻尼振动**
  - 核心问题：振动为什么会衰减，什么情况下不会来回振荡？
  - 首版范围：线性黏性阻尼弹簧振子，调整阻尼并比较欠阻尼、临界阻尼与过阻尼。
  - 验证重点：零阻尼极限、临界边界、能量非增与长期趋近平衡；说明初始条件的影响。
  - 学习联系：承接弹簧振子。

- [ ] **08 · 受迫振动与共振**
  - 核心问题：持续推动为什么有时能产生很大的振幅？
  - 首版范围：受正弦驱动力的线性阻尼振子，调整驱动频率、驱动力与阻尼，区分暂态、稳态及相位差。
  - 验证重点：稳态幅频响应、零驱动力、阻尼影响；若支持无阻尼共振，不能误用有限稳态振幅公式。
  - 学习联系：承接阻尼振动。

- [x] **09 · 驻波与振动模式**
  - 核心问题：两列反向传播的波为什么会形成静止的波节？
  - 首版范围：由等频等幅反向波形成驻波，观察波节、波腹；有限弦先采用明确的固定端条件和允许模式，再评估其他边界。
  - 验证重点：端点约束、波节位置、允许波长与模式频率；避免任意波长与固定边界相互矛盾。
  - 学习联系：承接波的叠加。
  - 状态：已上线（2026-10-13）。源码 `frontend/examples/physics/standing-wave`（参数模式数 n、振幅 A、弦长 L、波速 v；λₙ = 2L/n 由固定端导出），合并提交 `0bfe35e`，部署版本 `4fb6828e-139f-4c52-8c5c-622f85541ef2`。工程验证：`generate` 注册 12 个案例、`typecheck`、模型单测 14 项、`build` 78 页、Playwright e2e 全绿（含本案例回归测试）。案例状态仍为 experimental，独立教学审阅未完成。

- [x] **10 · 折射与全反射**
  - 核心问题：光穿过介质界面时为什么会转弯？
  - 首版范围：理想平面介质界面，调整入射角和两侧折射率，观察折射角及全反射临界情况。
  - 验证重点：垂直入射、相同折射率、临界角与全反射条件；未建模时不声称展示真实光强分配。
  - 学习联系：扩展透镜成像的光学基础。
  - 状态：已上线（2026-10-13）。源码 `frontend/examples/physics/refraction`（参数入射角 θ₁、两侧折射率 n₁、n₂），合并提交 `0bfe35e`，部署版本 `4fb6828e-139f-4c52-8c5c-622f85541ef2`。工程验证：`generate` 注册 12 个案例、`typecheck`、模型单测 12 项、`build` 78 页、Playwright e2e 全绿（含本案例回归测试）。只建模光线方向，不计算反射/折射强度分配。案例状态仍为 experimental，独立教学审阅未完成。

## 第三批：为长期电学工作台准备

前面三项是新增的过渡建议；自由搭建电学工作台是路线图已有的长期候选。先用固定电路验证教学价值和模型，再评估自由连接。

- [ ] **11 · 欧姆定律**
  - 核心问题：电压、电阻与电流有什么关系？
  - 首版范围：理想电源与正电阻组成的固定单回路，调整电压、电阻，观察电流与功率。
  - 验证重点：已知解、单位、功率关系与参数边界；不把理想短路当作有限电流状态。

- [ ] **12 · 串联与并联**
  - 核心问题：为什么串联分压、并联分流？
  - 首版范围：固定的两电阻串联、并联电路，调整电阻与电源，对比各支路电压、电流及等效电阻。
  - 验证重点：基尔霍夫定律、对称电阻、等效电阻及总功率。
  - 学习联系：承接欧姆定律。

- [ ] **13 · 电容充放电**
  - 核心问题：为什么电容两端的电压需要时间才能变化？
  - 首版范围：固定 RC 电路，调整 R、C 与电源电压，观察充放电曲线、初始电压与时间常数。
  - 验证重点：解析指数解、初始与长期状态、电压连续性；完整恢复电容内部状态，明确切换和重置语义。
  - 学习联系：从静态电路进入动态电路。

- [ ] **14 · 自由搭建电学工作台**
  - 核心问题：如何通过连接元件设计并解释一个电路？
  - 首版范围：有限的直流电阻网络与理想电源，支持连接及电压、电流读数；动态元件在后续独立评估。
  - 验证重点：元件协议、求解器、开路/短路/浮空与不一致电路、错误提示、键盘操作和真实手机连接交互。
  - 开始条件：固定电路案例已验证，确有自由搭建需求，并完成单独的交互、求解与维护范围设计。
  - 规划来源：路线图阶段五已有候选。

## 每个案例的共同交付要求

以下清单在每次选题实施记录中复制使用，不代表上述所有案例已经进入开发。

- [ ] 明确一个核心学习问题、先修知识、模型假设、单位、适用范围与首版边界。
- [ ] 完成独立模型及已知解、边界、守恒或收敛等相称验证。
- [ ] 完成实验视图、参数、读数与合理默认状态；需要动态模拟时明确步长、状态恢复及资源释放。
- [ ] 完成中英日七章讲解、labels、manifest、公式、预设、自测题、原创或获许可封面及 ATTRIBUTION。
- [ ] 与相关案例建立自然学习链接；接入目录、搜索、三语言实验页/讲解页与 SEO/sitemap。
- [ ] 完成类型、清单、构建和相关 Chrome 桌面/手机模拟交互检查，记录实际截图条件。
- [ ] 记录工程审查结论及限制；独立教学审阅未完成时保持 experimental。
- [ ] 按仓库授权提交、推送、发布，并核对正式页面、资源、跳转、真实 404 与 SEO；关联源码与部署版本。
- [ ] 单独记录实体设备验证、母语审校、独立教学审阅与真实学习反馈的实际状态和后续问题。
