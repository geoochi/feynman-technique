# なぜ2つの波は強め合ったり打ち消し合ったりするのか

同じ向きに、同じ直線上を進む2つの波は、各点で足し合わされる。どの位置でも、合成変位は2つの変位の代数和である。山と山が重なれば合成は大きくなり、山と谷が重なれば小さくなるか、完全に打ち消し合う。この実験では y₁ = A₁ sin(kx − ωt)、y₂ = A₂ sin(kx − ωt + φ) とその和 y = y₁ + y₂ を、共通の x 軸の上で時間とともに表示する。

## 問い
振幅が等しく位相差が 0 のとき、合成振幅は1つの波の何倍になる？

振幅が等しく位相差が π のとき、合成変位はどうなる？

一方の振幅を 0 にすると、合成変位には何が残る？

## 予想
まず予想を書こう。位相差を 0 から π へ増やすとき、合成振幅は一様に小さくなる？それとも大きいまま保たれ、π に近づくと急に小さくなる？

## 操作
再生を押し、3本の曲線がそろって +x 方向へ動くのを見る。A₁ = A₂ = 1.0 m、φ = 0 のまま合成振幅を記録し、次に φ を 180°（π）にして合成変位の曲線を見る。最後に A₂ を 0 にする。

## 観察
φ = 0 では2つの波が完全に重なり、合成振幅は1つの波の2倍になる。φ = π では2つの波がどこでも逆向きになり、合成変位は常に 0 で、完全に打ち消し合う。A₂ = 0 では合成変位は第1の波そのものになる。

## 解説
### 重ね合わせの原理
任意の位置 x と時刻 t で、合成変位は2つの変位の代数和である：y = y₁ + y₂。この実験では、2つの波が同じ方向（+x）へ進み、波長と振動数が等しく、媒質は線形で、境界も反射も減衰もないと仮定する。

### 位相ベクトル（フェーザー）で合成振幅を求める
A₁ と A₂ を角 φ をなす2つのベクトルとみなすと、合成ベクトルの長さが合成振幅になる：
A = √(A₁² + A₂² + 2A₁A₂ cos φ)。
φ = 0 なら A = A₁ + A₂、φ = π なら A = |A₁ − A₂|、A₁ = A₂ かつ φ = π なら A はちょうど 0 になる。

### 瞬間の変位とエネルギー
重ね合わせは変位の足し算であり、エネルギーの足し算ではない。位相差が π で振幅が等しいとき、変位は常に 0 である。この打ち消しは瞬間の変位の打ち消しであり、エネルギーまで打ち消されると考えるべきではない。エネルギーは振幅の2乗に関わり、より完全な解析が必要で、この実験では結論を出さない。

## 確かめ
A₁ = A₂ = 1.0 m、φ = 0 では合成振幅は 2.0 m と表示されるはず。φ を π にすると合成変位の曲線は零線上に重なり、A₂ を 0 にすると合成変位は第1の波と一致する。それぞれ数値表示と見比べよう。
