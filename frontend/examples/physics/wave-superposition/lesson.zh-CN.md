# 两列波为什么会加强或抵消？

沿同一方向在同一直线上传播的两列波，会在每个位置逐点相加：任意位置的合位移等于两列波各自位移的代数和。波峰与波峰相遇时合位移变大，波峰与波谷相遇时合位移变小甚至完全抵消。本实验展示 y₁ = A₁ sin(kx − ωt)、y₂ = A₂ sin(kx − ωt + φ) 以及它们的和 y = y₁ + y₂，并让三条曲线在同一 x 轴上随时间变化。

## 问题
两列波振幅相同、相位差为 0 时，合振幅是单列波的几倍？

两列波振幅相同、相位差为 π 时，合位移会变成什么样？

如果把其中一列波的振幅设为 0，合位移还剩下什么？

## 预测
先写下你的判断：相位差从 0 增大到 π 的过程中，合振幅是一直均匀变小，还是先保持较大、接近 π 时才迅速下降？

## 操作
点击播放，观察三条曲线一起沿 +x 方向移动。保持 A₁ = A₂ = 1.0 m、φ = 0，记下合振幅；再把 φ 调到 180°（π），观察合位移曲线；最后把 A₂ 调到 0。

## 观察
φ = 0 时两列波完全重合，合振幅是单列波的两倍。φ = π 时两列波处处相反，合位移始终为 0，完全抵消。A₂ = 0 时，合位移就等于第一列波。

## 解释
### 叠加原理
在任意位置 x 和任意时刻 t，合位移等于两列波各自位移的代数和：y = y₁ + y₂。本实验假设两列波沿同一方向（+x）传播、波长与频率相同、介质线性、没有边界反射、没有衰减。

### 用相量求合振幅
把 A₁ 与 A₂ 看作夹角为 φ 的两个矢量，合矢量的长度就是合振幅：
A = √(A₁² + A₂² + 2A₁A₂ cos φ)。
φ = 0 时 A = A₁ + A₂；φ = π 时 A = |A₁ − A₂|；当 A₁ = A₂ 且 φ = π 时 A 恰好为 0。

### 瞬时位移与能量
叠加说的是位移相加，不是能量相加。相位差为 π 且振幅相等时，位移始终为零；这里的抵消是瞬时位移的抵消，不能据此认为能量也被抵消。能量与振幅的平方有关，需要更完整的分析，本实验不做这一结论。

## 验证
A₁ = A₂ = 1.0 m、φ = 0 时，合振幅读数应为 2.0 m；把 φ 设为 π 时，合位移曲线应始终落在零线上；把 A₂ 设为 0 时，合位移应与第一列波重合。逐一与读数面板对照。
