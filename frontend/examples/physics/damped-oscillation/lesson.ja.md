# 減衰振動：振動はなぜ減るのか

現実の振動はほとんどが減衰する。空気や油の中を動くばね振り子には、速度と逆向きの抵抗力が働く。その抵抗力が速度に比例するとき F = −c x′ と書け、運動方程式は m x″ + c x′ + k x = 0 になる。固有角振動数 ω₀ = √(k/m) と減衰比 ζ = c / (2√(mk)) を導入すると、運動は ζ だけで決まる。ζ < 1 なら物体は振動を続けるが振幅は e^(−ζω₀t) で減っていく。ζ = 1 では振動せず、最も速く単調につり合いの位置へ戻る。ζ > 1 でも振動しないが、戻るのはむしろ遅くなる。力学的エネルギーは抵抗力に持ち去られるだけで、決して増えることはない。

## 問い
減衰係数 c を 0 から少しずつ大きくしていくと、振動はなぜ回を追うごとに小さくなり、最後には止まってしまうのか？

減衰比 ζ が 1 以上になると、物体はもうつり合いの位置を通り過ぎて戻ってくることはないのか？

減衰はそのままにして初期変位 x₀ だけを大きくすると、減衰の速さ（隣り合う山の比）は変わるのか？

## 予想
まず自分の予想を書いてみよう。ζ を 0.2 から 1 にすると、運動は「より速く振動する」だろうか、それとも「振動しなくなる」だろうか。過減衰（ζ > 1）と臨界減衰（ζ = 1）では、どちらが先につり合いの位置へ戻るだろうか。

## 操作
x₀ = 0.2 m から放して再生し、変位—時間グラフと包絡線を観察する。次に減衰係数 c を 0、2、10、25 N·s/m と順に変える（m = 1 kg、k = 25 N/m ではそれぞれ ζ = 0、0.2、1、2.5 に対応する）。変えるたびに再生し直そう。さらに質量 m を 4 kg にすると、臨界減衰係数 2√(mk) も一緒に動くことに注意しよう。どのパラメーターを変えても、選んだ変位で静止した状態から計り直される。

## 観察
ζ = 0 では振幅は変わらず、グラフは等振幅の正弦曲線で、力学的エネルギーの表示も一定のままである。0 < ζ < 1 では振動は続くが、山は包絡線 ±x₀e^(−ζω₀t) に押さえられ、減衰周期ごとに山の高さが同じ比で縮んでいく。ζ = 1 では曲線は x = 0 を横切らず、単調につり合いの位置へ近づく。ζ > 1 でも単調だが、しっぽが長く残る。どの場合でも力学的エネルギーの表示は減る一方である。

## 解説
### 抵抗力は何をしているのか
抵抗力 F = −c x′ は常に速度と逆向きなので、物体に対して負の仕事をする。すなわち dE/dt = −c v² ≤ 0 である。エネルギーが絶えず持ち去られることが減衰の原因である。c = 0 のときは dE/dt = 0 となり、力学的エネルギーは保存され、振幅は一定に保たれる。

### 振幅が指数関数的に減る理由
x = e^(λt) を m x″ + c x′ + k x = 0 に代入すると、特性方程式 mλ² + cλ + k = 0 が得られ、その根は λ = −ζω₀ ± ω₀√(ζ²−1) である。ζ < 1 では根は共役な複素数になり、解は x(t) = e^(−ζω₀t)[x₀cos(ω_d t) + ((v₀ + ζω₀x₀)/ω_d)sin(ω_d t)]、ただし ω_d = ω₀√(1−ζ²) となる。指数因子 e^(−ζω₀t) がそのまま包絡線であり、括弧の中が角振動数 ω_d の振動である。減衰は振動数をわずかに下げる（ω_d < ω₀）ので、減衰周期 T_d = 2π/ω_d は減衰のない周期 2π/ω₀ より少し長くなる。

### いつ振動しなくなるのか
ζ ≥ 1 では特性根が実数になり、解から正弦項が消える。ζ = 1 では x(t) = [x₀ + (v₀ + ω₀x₀)t]e^(−ω₀t) であり、静止から放した場合（v₀ = 0）は 2 つの係数の符号が同じなので、x は x₀ から 0 へ単調に減り、x = 0 を決して横切らない。ζ > 1 では x(t) = A e^(λ₁t) + B e^(λ₂t) で、2 つの根はどちらも負の実数なので同じく単調である。つまり振動するかどうかは ζ だけで決まり、ζ < 1 なら振動し、ζ ≥ 1 なら振動しない。なお過減衰は「減衰が大きいほど速く戻る」という意味ではない。ζ > 1 では最も遅い減衰率 −λ₁ = ω₀(ζ − √(ζ²−1)) が ζ とともに小さくなるため、戻るのに時間がかかる。振動しない場合の中で最も速く戻るのは臨界減衰である。

## 確かめ
c = 10 N·s/m にしよう（m = 1 kg、k = 25 N/m ではちょうど 2√(mk)）。表示は ζ = 1.000、運動の種類は「臨界減衰」、減衰周期は「振動しない」になるはずである。c = 2 N·s/m では ζ = 0.200、減衰周期は約 1.283 s、隣り合う山の比は約 e^(−ζω₀T_d) = 0.277 になる。c = 0 にすると包絡線は 2 本の水平線になり、力学的エネルギーの表示は一定のままである。k を変えずに m を 1 kg から 4 kg にすると ω₀ は半分になり、臨界減衰係数は 2√(4×25) = 20 N·s/m となって、もとの c = 10 N·s/m は不足減衰になる。x₀ だけを変えたときは ζ、ω₀、T_d は変わらず、力学的エネルギーが x₀² に比例して変わる。

## 発展
このモデルは速度に比例する粘性抵抗だけを考えている。現実の系には乾性摩擦（クーロン減衰）、空気抵抗、材料内部の損失もあり、それぞれ減衰の仕方が違う。乾性摩擦では振幅は指数関数的ではなく線形に減り、有限の時間で本当に止まりうる。さらに周期的な外力を加えると共振が起こるが、そのとき振幅は外力の振動数にどう依存するだろうか。[ばね振り子と周期](/labs/spring-oscillator)に戻って、減衰のない周期 T = 2π√(m/k) とここでの減衰周期 T_d = 2π/ω_d の違いを比べてみるのもよい。
