# 阻尼振动：振动为什么会衰减

真实世界里的振动几乎都会衰减：弹簧振子在空气或油中运动时，会受到与速度方向相反的阻力。若阻力正比于速度，F = −c x′，运动方程就变成 m x″ + c x′ + k x = 0。引入固有角频率 ω₀ = √(k/m) 和阻尼比 ζ = c / (2√(mk)) 之后，一切只取决于 ζ：ζ < 1 时物体仍然来回振荡，但振幅按 e^(−ζω₀t) 衰减；ζ = 1 时不再振荡，而是最快地单调回到平衡位置；ζ > 1 时同样不振荡，但回到平衡位置反而更慢。机械能只会被阻力带走，永远不会增加。

## 问题
把阻尼系数 c 从 0 慢慢调大，为什么振动会一次比一次小，最后停下来？

当阻尼比 ζ 达到 1 甚至更大时，物体还会冲过平衡位置再荡回来吗？

如果只把初始位移 x₀ 拉大而阻尼不变，衰减的快慢（也就是相邻峰值之比）会改变吗？

## 预测
先写下判断：ζ 从 0.2 增大到 1，运动是"振荡得更快"还是"不再振荡"？过阻尼（ζ > 1）与临界阻尼（ζ = 1）相比，哪一个先回到平衡位置？

## 操作
从 x₀ = 0.2 m 处释放并播放，观察位移—时间曲线与包络线。然后把阻尼系数 c 依次设为 0、2、10、25 N·s/m（在 m = 1 kg、k = 25 N/m 时分别对应 ζ = 0、0.2、1、2.5），每改一次都重新播放。再把质量 m 改成 4 kg，注意临界阻尼系数 2√(mk) 也会随之改变。改变任一参数都会从所选位移处的静止状态重新开始计时。

## 观察
ζ = 0 时振幅不变，位移—时间曲线是等幅正弦曲线，机械能读数在整个过程中保持不变。0 < ζ < 1 时曲线仍在振荡，但峰值被包络线 ±x₀e^(−ζω₀t) 越收越紧，每个阻尼周期的峰值都乘以同一个倍率。ζ = 1 时曲线不再穿过 x = 0，而是单调地贴近平衡位置。ζ > 1 时同样单调，但尾段拖得更长。所有情况下"机械能"读数都只减不增。

## 解释
### 阻力做了什么？
阻力 F = −c x′ 永远与速度反向，因此对物体做负功：dE/dt = −c v² ≤ 0。能量被不断抽走，这就是振幅衰减的根源。当 c = 0 时 dE/dt = 0，机械能守恒，振幅保持不变。

### 振幅为什么按指数规律衰减？
把 x = e^(λt) 代入 m x″ + c x′ + k x = 0，得到特征方程 mλ² + cλ + k = 0，两根为 λ = −ζω₀ ± ω₀√(ζ²−1)。当 ζ < 1 时两根是共轭复数，解为 x(t) = e^(−ζω₀t)[x₀cos(ω_d t) + ((v₀ + ζω₀x₀)/ω_d)sin(ω_d t)]，其中 ω_d = ω₀√(1−ζ²)。指数因子 e^(−ζω₀t) 就是包络线，括号内则是角频率为 ω_d 的振荡。阻尼让频率略微降低（ω_d < ω₀），所以阻尼周期 T_d = 2π/ω_d 比无阻尼周期 2π/ω₀ 略长。

### 什么情况下不再来回振荡？
当 ζ ≥ 1 时特征根变成实数，解里不再有正弦项。ζ = 1 时 x(t) = [x₀ + (v₀ + ω₀x₀)t]e^(−ω₀t)；从静止释放（v₀ = 0）时两项系数同号，x 从 x₀ 单调降到 0，永不穿过 x = 0。ζ > 1 时 x(t) = A e^(λ₁t) + B e^(λ₂t)，两根都是负实数，同样单调。因此"是否振荡"只由 ζ 决定：ζ < 1 振荡，ζ ≥ 1 不振荡。还要注意过阻尼并不等于"阻尼更大、回归更快"：ζ > 1 以后最慢的衰减率 −λ₁ = ω₀(ζ − √(ζ²−1)) 反而随 ζ 增大而减小，回归更慢；临界阻尼才是无振荡情形中回归最快的一个。

## 验证
把 c 设为 10 N·s/m（m = 1 kg、k = 25 N/m 时正好等于 2√(mk)），读数应显示 ζ = 1.000、状态为临界阻尼、阻尼周期为"不再振荡"。把 c 设为 2 N·s/m，读数应显示 ζ = 0.200、阻尼周期约 1.283 s，相邻峰值之比约为 e^(−ζω₀T_d) = 0.277。把 c 设为 0，包络线变成两条水平线，机械能读数保持不变。把 m 从 1 kg 改成 4 kg 而 k 不变，ω₀ 减半，临界阻尼系数变为 2√(4×25) = 20 N·s/m，原来的 c = 10 N·s/m 就变成欠阻尼了。只改变 x₀ 时 ζ、ω₀、T_d 都不变，而机械能按 x₀² 成比例变化。

## 延伸
本模型只考虑了正比于速度的粘滞阻力。真实系统里还有干摩擦（库仑阻尼）、空气阻力和材料内耗，它们对应的衰减规律各不相同：干摩擦会让振幅按线性而不是指数规律减小，并可能在有限时间内真正停下。如果再给振子加一个周期性外力，就会出现共振——那时振幅与外力频率的关系又是怎样的？也可以回到[弹簧振子与周期](/labs/spring-oscillator)，比较无阻尼周期 T = 2π√(m/k) 与这里阻尼周期 T_d = 2π/ω_d 的差别。
