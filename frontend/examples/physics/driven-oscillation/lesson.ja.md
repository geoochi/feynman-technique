# 強制振動と共振

減衰するばね振り子に周期的な外力をつなぎ、ずっと押し続ける。しばらくすると過渡状態が消え、振り子は外力の角振動数 ω_d で振動する定常状態に落ち着く。その定常振幅は A = F₀/√((k−mω_d²)²+(cω_d)²) で、変位は外力より φ = atan2(cω_d, k−mω_d²) だけ遅れる。要点は、駆動角振動数が固有角振動数 ω₀ = √(k/m) に近づくと振幅が最大になること（これが共振）と、減衰が大きいほどピークが低く広くなることである。外力がゼロなら振り子はエネルギーを減衰で失うだけで止まる。まず外力がない場合を見たいときは[減衰振動](/ja/labs/damped-oscillation)に戻ろう。

## 問い
ずっと押し続けているのに、振幅がとても小さいときと、どんどん大きくなるときがあるのはなぜ？

駆動角振動数が固有角振動数 ω₀ = √(k/m) に近づくと、定常振幅が急に大きくなるのはなぜ？

減衰係数 c を大きくすると、共振のピークは高くなるのか、それとも低くなるのか？

## 予想
まず予想を書こう。駆動角振動数 ω_d を小さい値から大きい値へ変えていくと、定常振幅は増え続けるか、それとも途中で最大になってから減るか。減衰 c を2倍にすると、ピークの高さはおよそ半分になるか。

## 操作
既定の値（m = 1 kg、k = 30 N/m、c = 0.8 N·s/m、F₀ = 2 N、ω_d = 5.5 rad/s）から始め、再生を押す。変位—時間の軌跡に注目する。最初は振幅が小さく、しだいに大きくなって落ち着く。破線は定常状態の包絡線 ±A である。ω_d を 2、5.5、11 rad/s と変え、数値パネルの定常振幅 A と位相の遅れ φ を記録し、応答曲線の印と見比べる。次に c を 0.4 と 5 N·s/m にして共振のピークの鋭さを比べる。最後に F₀ = 0 にして軌跡がゼロへ減衰するのを見る。

## 観察
ω₀ から離れると定常振幅は小さい。ω_d = 2 rad/s で A ≈ 0.077 m、ω_d = 11 rad/s で A ≈ 0.022 m である。ω_d = 5.5 rad/s は ω₀ = √(30/1) ≈ 5.477 rad/s に近く、A ≈ 0.454 m となり、両端よりずっと大きい。c を 0.8 から 0.4 へ下げるとピークは約2倍の 0.90 m になり、5 へ上げると約 0.073 m まで平らになる。位相の遅れ φ は低い振動数でほぼ 0° から高い振動数でほぼ 180° まで単調に増え、共振付近では約 90° になる。始めには過渡状態があり、振幅はゼロから増えて約 2m/c ≈ 2.5 s で定常値に近づく。F₀ = 0 では定常状態はなく、軌跡は減衰して静止する。

## 解説
### 定常解の導き方
x = A cos(ω_d t − φ) を m x″ + c x′ + k x = F₀ cos(ω_d t) に代入する。変位・速度・加速度の振幅はそれぞれ A、Aω_d、Aω_d² である。外力と同位相の成分と4分の1周期遅れた成分に分けると、前者の係数は k − mω_d²、後者の係数は cω_d となり、合成した大きさは √((k−mω_d²)²+(cω_d)²) になる。したがって A = F₀/√((k−mω_d²)²+(cω_d)²)、φ = atan2(cω_d, k − mω_d²) である。

### なぜ ω₀ = √(k/m) の近くで最大になるのか
振幅は分母が最も小さいところで最大になる。減衰がなければ分母は |k − mω_d²| で、ω_d = √(k/m) = ω₀ でゼロになり振幅は発散する。これが減衰のない理想的な共振の極である。減衰があると cω_d の項が ω₀ の近くにゼロでない下限を作り、振幅は有限に保たれる。ω_d = ω₀ では A = F₀/(cω₀) である。減衰が小さいほど下限が低くなり、ピークは高く鋭くなる。

### 過渡状態・定常状態・位相の遅れ
一般解は定常解と、e^{−(c/2m)t} で減衰する過渡解の和である。静止から始めると過渡解は無視できず、振幅はおよそ 2m/c の時間をかけて増え、その後で定常状態になる。位相の遅れ φ は、変位が外力よりどれだけ遅れるかを表す。共振よりずっと低い振動数では φ ≈ 0 で、変位は外力とほぼ同位相である。共振では φ ≈ 90° となり、変位は4分の1周期遅れ、速度が外力と同位相になって入力仕事が最大になる。共振よりずっと高い振動数では φ → 180° となり、変位は外力とほぼ逆位相になる。

### 減衰と F₀ = 0 の場合
減衰は −c v を通じて力学的エネルギーを散逸させる。したがって F₀ = 0 では振り子は減衰振動をするだけで、振幅は e^{−(c/2m)t} で減衰して静止する。定常状態は存在しない。F₀ > 0 では外力がエネルギーを供給し続け、定常振幅は F₀ に比例し、減衰に反比例する。

## 確かめ
m = 1 kg、k = 30 N/m、c = 0.8 N·s/m、F₀ = 2 N とする。ω_d = 5.5 rad/s で A ≈ 0.454 m、φ ≈ 93°；ω_d = 2 rad/s で A ≈ 0.077 m、φ ≈ 4°；ω_d = 11 rad/s で A ≈ 0.022 m、φ ≈ 175° となるはずである。c = 0.4 N·s/m にすると A は約2倍の 0.90 m、c = 5 N·s/m にすると約 0.073 m まで下がる。F₀ = 0 では軌跡がゼロへ減衰し、定常振幅は 0、位相の遅れは数値ではなく記号で表示される。1 ステップで 0.10 s ずつ進め、過渡状態と定常状態の包絡線の違いを確かめよう。

## 発展
外力が正弦的でない場合（周期的な方形波など）、定常状態を1つの振幅で表せるだろうか。同じ振り子を固有振動数の異なる別の方向にもつないだら、何が起こるだろうか。外力がないときに減衰がエネルギーを奪うようすは[減衰振動](/ja/labs/damped-oscillation)で、ω₀ = √(k/m) の由来は[ばね振り子と周期](/ja/labs/spring-oscillator)で確認しよう。
