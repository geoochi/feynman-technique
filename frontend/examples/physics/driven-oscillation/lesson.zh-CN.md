# 受迫振动与共振

把带阻尼的弹簧振子接在一个周期性的外力上，让它一直被推着走。过一段时间后，暂态消失，振子会稳定在以外力频率 ω_d 振动的状态，稳态振幅为 A = F₀/√((k−mω_d²)²+(cω_d)²)，位移比外力落后 φ = atan2(cω_d, k−mω_d²)。核心结论是：当驱动频率接近系统的固有频率 ω₀ = √(k/m) 时，振幅会出现明显的峰值——这就是共振；阻尼越大，峰值越低、越平缓。如果外力为零，振子只会把已有的能量通过阻尼耗散掉，最终停下。想先看清“没有外力时会怎样”，可以回到[阻尼振动](/zh/labs/damped-oscillation)。

## 问题
一直用力推一个振子，为什么有时振幅很小，有时却能越推越大？

驱动频率接近固有频率 ω₀ = √(k/m) 时，稳态振幅为什么会急剧上升？

把阻尼系数 c 调大，共振峰是变高还是变低？

## 预测
先写下你的判断：把驱动频率 ω_d 从很小逐渐调大，稳态振幅会一直增大，还是先升后降？把阻尼 c 加倍，共振峰的高度会大约减半吗？

## 操作
从默认参数开始（m = 1 kg、k = 30 N/m、c = 0.8 N·s/m、F₀ = 2 N、ω_d = 5.5 rad/s），点击播放，注意位移—时间轨迹：一开始振幅很小，随后逐渐增大并趋于稳定，虚线是稳态包络 ±A。把 ω_d 依次设为 2、5.5、11 rad/s，记下读数面板中的稳态振幅 A 与相位差 φ，并对照幅频曲线上的标记。再把 c 设为 0.4 与 5 N·s/m，比较共振峰的陡峭程度。最后把 F₀ 设为 0，观察轨迹如何衰减到零。

## 观察
ω_d 远离 ω₀ 时稳态振幅很小：ω_d = 2 rad/s 时 A ≈ 0.077 m，ω_d = 11 rad/s 时 A ≈ 0.022 m。当 ω_d = 5.5 rad/s 接近 ω₀ = √(30/1) ≈ 5.477 rad/s 时，A ≈ 0.454 m，远大于两端。把 c 从 0.8 减到 0.4，共振峰高度约翻倍到 0.90 m；把 c 加到 5，峰值被压到约 0.073 m，曲线变得平坦。相位差 φ 从低频端的接近 0° 单调增加到高频端的接近 180°，在共振点附近约为 90°。运动刚开始时还有一段暂态：振幅从零逐步增长，约经过 2m/c ≈ 2.5 s 才接近稳态。F₀ = 0 时没有稳态，轨迹按阻尼振动衰减到静止。

## 解释
### 稳态解从何而来
把 x = A cos(ω_d t − φ) 代入 m x″ + c x′ + k x = F₀ cos(ω_d t)。位移、速度、加速度的振幅分别是 A、Aω_d、Aω_d²。把它们按“与外力同相”和“落后四分之一周期”两个分量拆开，前者的系数是 k − mω_d²，后者的系数是 cω_d，两者合成的幅值为 √((k−mω_d²)²+(cω_d)²)。因此 A = F₀/√((k−mω_d²)²+(cω_d)²)，相位差 φ = atan2(cω_d, k − mω_d²)。

### 为什么峰值出现在 ω₀ = √(k/m) 附近
振幅在分母最小时最大。忽略阻尼时分母是 |k − mω_d²|，在 ω_d = √(k/m) = ω₀ 处为零，振幅发散——这就是无阻尼理想共振的极点。有阻尼时，虚部 cω_d 在 ω₀ 附近留下一个非零的“地板”，使振幅保持有限：在 ω_d = ω₀ 处 A = F₀/(cω₀)。阻尼越小，这个地板越低，峰越高、越窄。

### 暂态、稳态与相位差
通解是稳态解加上一个按 e^{−(c/2m)t} 衰减的暂态。从静止出发时暂态不可忽略，振幅在约 2m/c 的时间内增长，之后才进入稳态。相位差 φ 描述位移落后于外力多少：远低于共振时 φ ≈ 0，位移几乎与外力同步；共振时 φ ≈ 90°，位移落后四分之一周期，此时速度与外力同相，外力做功的功率最大；远高于共振时 φ → 180°，位移与外力几乎反向。

### 阻尼与 F₀ = 0
阻尼通过 −c v 不断耗散机械能。所以 F₀ = 0 时振子只做阻尼振动，振幅按 e^{−(c/2m)t} 衰减到静止，不存在稳态。F₀ > 0 时外力持续输入能量，稳态振幅与 F₀ 成正比，与阻尼成反比。

## 验证
取 m = 1 kg、k = 30 N/m、c = 0.8 N·s/m、F₀ = 2 N。ω_d = 5.5 rad/s 时读数应为 A ≈ 0.454 m、φ ≈ 93°；ω_d = 2 rad/s 时 A ≈ 0.077 m、φ ≈ 4°；ω_d = 11 rad/s 时 A ≈ 0.022 m、φ ≈ 175°。把 c 改为 0.4 N·s/m，A 应约翻倍到 0.90 m；改为 5 N·s/m，A 应降到约 0.073 m。把 F₀ 设为 0，轨迹应逐渐衰减到零，读数面板的稳态振幅为 0，相位差不再显示数字。用“单步”按钮每次推进 0.10 s，比较暂态与稳态包络之间的差距。
