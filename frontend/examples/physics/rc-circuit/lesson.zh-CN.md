# RC 电路与时间常数

电容两端的电压不会瞬间跳到电源电动势，因为改变电容电压必须搬运电荷，而电荷只能通过电阻流动：电流被电阻限制，电压就只能以有限的速率变化。把基尔霍夫电压定律 E = iR + u 与电容关系 i = C du/dt 合起来，得到 RC du/dt = E − u，解为 u(t) = E + (u₀ − E)e^(−t/τ)，其中 τ = RC。开关在 t = 0 时闭合，电容从 u₀ 开始；经过一个时间常数 τ，电容电压与 E 的差距缩小到原来的 1/e；当 t → ∞ 时 u → E。它与[欧姆定律](/labs/ohms-law)和[串联与并联](/labs/series-parallel)用的是同一套电路规律，只是多了会储存电荷的电容，于是过程有了时间。

## 问题
为什么电容两端的电压不会瞬间跳到电源电动势，而是需要时间慢慢变化？

把电阻 R 或电容 C 调大，电容电压趋向电源电动势的过程会变慢还是变快？

如果电容一开始就带着比电源更高的电压（u₀ > E），它会先放电还是继续充电，最后稳定在哪里？

## 预测
先写下判断：u₀ = 0、E = 6 V 时，经过一个时间常数 τ 后电容电压大约是 6 V 的 63%、86% 还是 95%？把 τ 变为 4 倍后，达到同一个比例所需的时间会变为几倍？再把 u₀ 设为 10 V、E 设为 0 V，预测曲线是上升还是下降。

## 操作
保持 E = 6 V、u₀ = 0 V、R = 40 Ω、C = 0.05 F，此时 τ = RC = 2 s。播放并观察曲线：它从 u₀ 出发，向 E 靠近。暂停后用"单步"每次前进 0.10 s，记下 t = 0.10、1.00、2.00 s 时的电容电压读数。再把电容 C 改为 0.1 F，τ 变为 4 s，重新播放并比较曲线变缓的程度。最后把 u₀ 设为 10 V、E 设为 0 V，观察放电。开关在 t = 0 时闭合；改变任一参数（或按下重置）都会重新断开电路、把模拟时间归零，并把电容电压恢复为 u₀——电容的内部状态就是它两端的电压，恢复时也是按这个电压继续。

## 观察
曲线从 u₀ 出发，单调地趋向 E，既不跳过 E 也不在 E 处折返。τ 越大曲线越平缓，τ 越小曲线越陡；改变 R 或 C 只改变快慢，不改变最终的 E。当 u₀ < E 时曲线上升（充电），当 u₀ > E 时曲线下降（放电），当 u₀ = E 时曲线是一条水平线。默认参数下 t = 0 附近曲线是斜的而不是竖直的，说明电压的变化率有限；把 τ 调到很小（例如 0.2 s）时，同一个变化就被压缩到窗口最左端很窄的一段里。

## 解释
### 为什么电容电压不能跳变？
电容储存的电荷 q 与电压满足 q = C u，而电流是电荷的搬运速率 i = dq/dt = C du/dt。回路中电荷只能通过电阻流动，电阻把电流限制在 i = (E − u)/R，于是 du/dt = (E − u)/(RC) 始终有限。有限的变化率意味着电压随时间连续变化，不可能在某一瞬间跳到 E。只有当 R → 0 时变化率才会趋于无限大，那正是理想短路的情形。

### 指数解从哪里来？
沿回路应用基尔霍夫电压定律：电源电动势 E 等于电阻上的电压降 iR 加上电容电压 u，即 E = iR + u。代入 i = C du/dt 得 RC du/dt + u = E。这是一个一阶线性方程，分离变量后 du/(E − u) = dt/(RC)，积分得 u(t) = E + (u₀ − E)e^(−t/τ)，其中 τ = RC。两个常数直接给出两端的极限：t = 0 时 u = u₀，t → ∞ 时指数项趋于 0、u → E。

### 时间常数 τ 意味着什么？
τ = RC 的单位是秒，是这个过程唯一的时间尺度。经过一个 τ，电容电压与 E 的差距变为原来的 1/e ≈ 0.368；从 u₀ = 0 充电时 u(τ) = E(1 − 1/e) ≈ 0.632E。经过 5τ 后差距只剩约 0.7%，工程上就认为过程结束。电流 i(t) = ((E − u₀)/R)e^(−t/τ) 在 t = 0 时最大，随后按同一指数衰减。注意 τ 只由 R 与 C 的乘积决定，R 与 C 互换（例如 R 减半、C 加倍）曲线形状完全不变。

## 验证
默认参数下 τ = 40 × 0.05 = 2 s。单步到 t = 0.10 s 时读数应约为 u = 6(1 − e^(−0.05)) ≈ 0.293 V；单步到 t = 2.00 s 时应约为 6(1 − 1/e) ≈ 3.793 V；单步到 t = 10.00 s 时应约为 6(1 − e^(−5)) ≈ 5.960 V，即差距只剩约 0.7%。把 C 改为 0.1 F，τ 变为 4 s，t = 2.00 s 时读数应约为 6(1 − e^(−0.5)) ≈ 2.361 V，明显小于 3.793 V。把 R 从 40 Ω 改为 80 Ω，曲线应与上一步完全重合，因为 τ 都是 4 s。反过来把 R 减半到 20 Ω、同时把 C 加倍到 0.1 F，τ 仍是 2 s，曲线与默认情形完全一致。把 u₀ 设为 10 V、E 设为 0 V，t = 2.00 s 时读数应约为 10/e ≈ 3.679 V。把 u₀ 设为与 E 相同，电流读数应为 0 A，曲线保持水平。

## 延伸
真实电路里还有电源内阻、电容的漏电流和导线的寄生电容电感，它们会让曲线偏离理想指数；电容的等效串联电阻还会在开关瞬间产生一个很小的电压跳变。如果电源不是恒定的 EMF 而是随时间变化（例如方波），电容电压会怎样响应？把两个 RC 电路级联，会出现什么样的曲线？也可以回到[欧姆定律](/labs/ohms-law)看纯电阻回路的瞬时响应，或到[串联与并联](/labs/series-parallel)比较电阻的等效规律与这里电容的储能规律。
