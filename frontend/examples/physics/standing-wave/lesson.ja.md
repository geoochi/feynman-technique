# 定常波と節

振動数と振幅が等しい2つの波を、同じ弦の上で逆向きに進ませる。1つは右へ、1つは左へ進む。出会ったところで各点ごとに足し合わされ、その結果は行ったり来たりする波形の寄せ集めではなく、全体が同じリズムで上下に振れる1本の曲線になる。まったく動かない点があり、いちばん大きく振れる点もある。動かない点を節、最も大きく振れる点を腹という。この実験では y₁ = A sin(kx − ωt) と y₂ = A sin(kx + ωt) を足し、y = 2A sin(kx)cos(ωt) を得る。空間の因子 sin(kx) と時間の因子 cos(ωt) が分離するのが「定常波」という名前の由来である。両端が固定されていると sin(kL) = 0 が要求され、波長は λₙ = 2L/n しか取れなくなる。モード数 n は、弦の上に半波長がいくつ入るかを表す。

## 問い
振動数と振幅が等しい2つの波が逆向きに進むとき、合成変位はなぜ y = 2A sin(kx)cos(ωt) と書けるのか。どちらか一方へ進み続けないのはなぜ？

弦の両端が固定されているとき、波長は自由に選べず λₙ = 2L/n を満たさなければならないのはなぜ？

節では弦がまったく動かない。そこには本当にエネルギーがないのか？

## 予想
まず予想を書こう。モード数 n を 1 から 6 へ増やすと、節は増えるか減るか。波長は長くなるか短くなるか。振幅 A を2倍にすると、節の位置は動くか。

## 操作
再生を押し、2本の細い曲線が逆向きに進み、太い曲線が全体として上下に振れるようすを見る。L = 2 m、v = 8 m/s のままモード数を n = 1、2、3 と変え、数値パネルの許される波長 λₙ、振動数 fₙ、節の数を記録する。次に振幅 A を 0.10 m から 0.20 m へ上げ、節が動くかどうかを見る。最後にアニメーションを t = 0 と約4分の1周期の位置で止め、曲線の形を比べる。

## 観察
太い曲線はいつも同じ不動点を通る。それが節である。隣り合う節の間で曲線は最も大きく振れ、その中点が腹になる。n = 2、L = 2 m では節は 0 m、1.0 m、2.0 m にあり、波長は λ₂ = 2.0 m、振動数は f₂ = 4 Hz である。n = 3 では節は 0 m、0.67 m、1.33 m、2.00 m に増え、波長は λ₃ ≈ 1.33 m に短くなり、振動数は f₃ = 6 Hz に上がる。振幅 A を変えても振れの大きさが変わるだけで、節の位置はまったく動かない。2本の細い曲線（y₁ と y₂）は、どの節でも大きさが等しく向きが逆なので合成はゼロになり、腹では同じ向きに重なって合成振幅は1つの波の2倍になる。

## 解説
### 逆向きに進む2つの波の足し算
右へ進む波 y₁ = A sin(kx − ωt) と左へ進む波 y₂ = A sin(kx + ωt) は各点で代数的に足し合わされる。和積の公式 sin α + sin β = 2 sin((α+β)/2)cos((α−β)/2) で α = kx − ωt、β = kx + ωt とおくと y = 2A sin(kx)cos(ωt) を得る。位置と時間が2つの独立な因子に分かれ、sin(kx) が各位置の振れ幅を、cos(ωt) がその瞬間に全体がどこにあるかを決める。

### 固定端が波長を決める
両端が固定されているとは、いつでも y(0, t) = 0 かつ y(L, t) = 0 ということである。y = 2A sin(kx)cos(ωt) を見ると、x = 0 では sin(0) = 0 で自動的に満たされる。x = L では sin(kL) = 0、すなわち kL = nπ（n = 1, 2, 3, …）が必要である。k = 2π/λ を代入すると λₙ = 2L/n となり、両端の間に半波長がちょうど n 個入る。波長は自由なパラメーターではなく、モード数 n から導かれる。許される波長は 2L、L、2L/3、L/2、… だけであり、モードの振動数は fₙ = v/λₙ = n v /(2L) に決まる。

### 節と腹
節は sin(kx) = 0 となる場所、つまり x = kL/n（k = 0, 1, …, n）に現れ、両端も含めて n + 1 個ある。そこでは sin(kx) が常にゼロなので、cos(ωt) が何であっても変位はゼロのままで、「動かない」という性質が生まれる。隣り合う節の中点では |sin(kx)| = 1 となり、変位は ±2A の間で振れる。これが最も振れ幅の大きい腹で、n 個ある。「動かない」とは変位が常にゼロという意味であり、エネルギーは節と腹の間を行き来しているので、節にエネルギーがないわけではない。

## 確かめ
L = 2 m、v = 8 m/s とする。n = 2 では λ₂ = 2.000 m、f₂ = 4.000 Hz、節の数 3 と表示されるはず。n = 3 では λ₃ ≈ 1.333 m、f₃ = 6.000 Hz、節の数 4 となる。振幅 A をどんな値にしても、節の数値と節の位置は変わらず、腹の振れ幅だけが変わるはずである。再生中、4分の1周期では曲線はほぼ零線まで平らになり、さらに4分の1周期後には t = 0 と逆の位相で戻る。それぞれ数値パネルと見比べよう。

## 発展
2つの波の振幅が等しくないと、節は完全に止まったままでいられるだろうか。弦の一端を固定せず自由端にしたら、許される波長はどうなるだろうか。まず[波の重ね合わせ](/ja/labs/wave-superposition)で、同じ向きに進む波の強め合いと打ち消しを確かめ、そのうえで逆向きに進むと定常波ができる理由を考えよう。
