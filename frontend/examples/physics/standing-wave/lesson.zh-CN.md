# 驻波与波节

把两列频率相同、振幅相同的波沿相反方向送进同一根弦：一列向右传播，一列向左传播。它们相遇后逐点相加，得到的不是一团来回乱动的波形，而是一条整体按同一节奏上下振动的曲线——有些位置始终不动，有些位置振幅最大。始终不动的位置叫波节，振幅最大的位置叫波腹。本实验把 y₁ = A sin(kx − ωt) 与 y₂ = A sin(kx + ωt) 相加，得到 y = 2A sin(kx)cos(ωt)：空间部分 sin(kx) 与时间部分 cos(ωt) 分离，这正是“驻波”名字的由来。两端固定要求 sin(kL) = 0，于是波长只能取 λₙ = 2L/n，模式数 n 决定了弦上能放下几个半波长。

## 问题
两列频率相同、振幅相同的波沿相反方向传播，它们的合位移为什么可以写成 y = 2A sin(kx)cos(ωt)，而不是继续向某一侧移动？

弦的两端固定时，为什么波长不能任意选取，而必须满足 λₙ = 2L/n？

波节处弦始终不动，那里真的“没有能量”吗？

## 预测
先写下你的判断：把模式数 n 从 1 增大到 6，波节会变多还是变少？波长会变长还是变短？再把振幅 A 加倍，波节的位置会不会移动？

## 操作
点击播放，观察两列细线反向移动、粗实线整体上下振动。保持 L = 2 m、v = 8 m/s，依次把模式数设为 n = 1、2、3，记下读数面板里的波长 λₙ、频率 fₙ 与波节数。然后把振幅 A 从 0.10 m 调到 0.20 m，注意波节是否移动。最后让动画停在 t = 0 和大约四分之一周期处，比较曲线的形状。

## 观察
粗实线始终穿过同一组不动点，这些点就是波节；相邻波节之间，曲线上下摆动的幅度最大，中点就是波腹。n = 2、L = 2 m 时波节在 0 m、1.0 m、2.0 m，波长 λ₂ = 2.0 m，频率 f₂ = 4 Hz；n = 3 时波节增加到 0 m、0.67 m、1.33 m、2.00 m，波长缩短为 λ₃ ≈ 1.33 m，频率升高到 f₃ = 6 Hz。改变振幅 A 只改变摆动的大小，波节位置完全不变。在两列细线（y₁ 与 y₂）里，每个波节处两列波恰好大小相等、方向相反，所以合位移为零；波腹处两列波同向叠加，合振幅是单列波的两倍。

## 解释
### 两列反向传播的波如何相加
向右传播的波 y₁ = A sin(kx − ωt) 与向左传播的波 y₂ = A sin(kx + ωt) 在每一点代数相加。利用和差化积公式 sin α + sin β = 2 sin((α+β)/2)cos((α−β)/2)，取 α = kx − ωt、β = kx + ωt，得到 y = 2A sin(kx)cos(ωt)。位置与时间被拆成两个独立的因子：sin(kx) 决定每个位置能摆动多大，cos(ωt) 决定全体在同一时刻摆到哪里。

### 固定端如何限定波长
两端固定意味着任意时刻都有 y(0, t) = 0 与 y(L, t) = 0。由 y = 2A sin(kx)cos(ωt) 可见，x = 0 处 sin(0) = 0 自动满足；x = L 处则要求 sin(kL) = 0，即 kL = nπ（n = 1, 2, 3, …）。代入 k = 2π/λ 得 λₙ = 2L/n，也就是弦上恰好容纳 n 个半波长。波长不是自由参数，而是由模式数 n 导出的：允许的波长只有 2L、L、2L/3、L/2……模式频率随之确定为 fₙ = v/λₙ = n v /(2L)。

### 波节与波腹
波节出现在 sin(kx) = 0 处，即 x = kL/n（k = 0, 1, …, n），一共 n + 1 个，两端也在其中。因为 sin(kx) 恒为零，无论 cos(ωt) 取何值，这些点的位移始终为零——这就是“静止”的来源。相邻两个波节的中点满足 |sin(kx)| = 1，位移在 ±2A 之间摆动，是振幅最大的波腹，共 n 个。注意“不动”说的是位移始终为零；能量在波节与波腹之间往复转移，不能说波节处没有能量。

## 验证
取 L = 2 m、v = 8 m/s：n = 2 时读数应为 λ₂ = 2.000 m、f₂ = 4.000 Hz、波节数 3；n = 3 时 λ₃ ≈ 1.333 m、f₃ = 6.000 Hz、波节数 4。把振幅 A 改成任意值，波节读数与波节位置都不应改变，只有波腹的摆动幅度变化。播放时让动画经过四分之一周期，曲线应几乎压平到零线；再经过四分之一周期，曲线应回到与 t = 0 相反的相位。逐一与读数面板对照。
