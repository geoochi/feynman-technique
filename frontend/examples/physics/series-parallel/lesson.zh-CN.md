# 串联与并联

串联电路中电流处处相同，电源电压按阻值比例分配给各个电阻（分压）；并联电路中各支路电压相同，电源电流按电阻的反比分配给各条支路（分流）。串联的等效电阻 R_eq = R₁ + R₂ 总比每个电阻都大，并联的等效电阻满足 1/R_eq = 1/R₁ + 1/R₂，总比每个电阻都小。两条电路共用同一电源 V 与相同的 R₁、R₂ 时，串联的电流与总功率都更小，并联的电流与总功率都更大。

## 问题
为什么串联电路中两个电阻分得的电压之和恰好等于电源电压？

为什么并联电路中两条支路的电流之和恰好等于电源送出的总电流？

为什么串联的等效电阻总比每个电阻大，而并联的等效电阻总比每个电阻小？

## 预测
先不要改动参数。请预测：保持 V 与 R₂ 不变，把 R₁ 从 100 Ω 增大到 300 Ω，串联电路的电流 I 会变大还是变小？并联电路的总电流 I 又会怎样变化？把判断写下来，再和实验对照。

## 操作
保持 V = 6 V、R₂ = 300 Ω 不变，把 R₁ 依次取 100 Ω、300 Ω、1000 Ω，每次记录串联的 I、V₁、V₂，并联的 I₁、I₂、总电流 I，以及两种电路的等效电阻。再固定 R₁ = R₂ = 100 Ω，改变电源电压 V，观察电流与电压如何按比例变化。

## 观察
串联时 V₁ + V₂ = V，电流处处相同，R_eq = R₁ + R₂ 总大于任一电阻；并联时 I₁ + I₂ = I，两条支路电压相同，R_eq 总小于任一电阻。当 R₁ = R₂ = 100 Ω 时，串联 R_eq = 200 Ω，并联 R_eq = 50 Ω。串联电流 I = V/(R₁+R₂)，并联总电流 I = V/R₁ + V/R₂ = V/R_eq。把 R₁ 从 100 Ω 增大到 300 Ω 时，串联电流变小，并联总电流也变小。

## 解释
### 为什么串联分压
串联电路只有一条路径，电荷不会在某处堆积，所以电流处处相同：I = V/(R₁+R₂)。由欧姆定律，两个电阻上的电压分别是 V₁ = I·R₁ 与 V₂ = I·R₂，两者相加正好等于电源电压 V，阻值越大分得的电压越多。

### 为什么并联分流
并联的两条支路接在同一对节点上，所以电压相同，都等于电源电压 V。每条支路的电流由欧姆定律决定：I₁ = V/R₁、I₂ = V/R₂。电源送出的电流必须在节点处分成这两支，于是 I = I₁ + I₂，阻值越小分得的电流越多。

### 等效电阻
把两个电阻看成一个整体：串联时电压相加而电流相同，所以 R_eq = R₁ + R₂，比每个电阻都大；并联时电流相加而电压相同，所以 1/R_eq = 1/R₁ + 1/R₂，R_eq 比每个电阻都小。当 R₁ = R₂ = R 时，串联 R_eq = 2R，并联 R_eq = R/2，并联恰好是串联的四分之一。

## 验证
取 V = 6 V、R₁ = 100 Ω、R₂ = 200 Ω。串联：R_eq = 300 Ω，I = 0.02 A，V₁ = 2 V，V₂ = 4 V，且 V₁ + V₂ = 6 V = V。并联：I₁ = 0.06 A，I₂ = 0.03 A，I = 0.09 A，且 I₁ + I₂ = I；R_eq = 200/3 ≈ 66.7 Ω，总功率 P = V·I = 0.54 W。再用 P = V²/R_eq 核对一遍。

## 延伸
当两个电阻相等（R₁ = R₂ = R）时，并联等效电阻恰好是串联的四分之一，请自行推导验证。也可以改变 R₁ 与 R₂ 的比例，观察分压与分流如何随比例变化。想比较另一个实验如何用公式描述变化规律，可以阅读[薄透镜成像](/zh/labs/thin-lens)。
