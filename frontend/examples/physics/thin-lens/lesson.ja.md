# 薄レンズと像

薄い凸レンズと近軸光線では、薄レンズの式 1/u + 1/v = 1/f が像を決める。物体距離 u は常に正、凸レンズの焦点距離 f は正、像距離 v はレンズの反対側の実像で正、物体と同じ側の虚像で負である。横倍率は m = −v/u で、m < 0 は倒立の実像、m > 0 は正立の虚像を表す。物体がレンズに近づくと像の位置・大きさ・実虚が変わり、u = f では出射光が平行になって有限の像ができない。

## 問い
物体が凸レンズに近づくとき、像の位置はどのように変わる？

物体距離が f と 2f の間にあるとき、実像が物体より大きくなるのはなぜ？

u = f のとき、スクリーンをどこに置いてもはっきりした像ができないのはなぜ？

## 予想
何も動かす前に予想しよう。物体距離 u を 2f から 1.5f に小さくすると、像距離 v は大きくなるか小さくなるか。像は大きくなるか小さくなるか。予想を書いてから実験と比べよう。

## 操作
f = 0.10 m、h = 0.03 m のまま物体距離 u だけを変える。u = 2f、u = 1.5f、u = f、u = 0.5f の順に試し、そのつど像距離 v、倍率 m、実像か虚像かを記録しよう。破線に注目：実像は実際の光線が交わる点に、虚像は光線の逆向き延長線が交わる点にできる。

## 観察
u > 2f では倒立・実像・縮小、u = 2f では倒立・実像・等大、f < u < 2f では倒立・実像・拡大になる。u = f では出射光が平行になり有限の像はできない。u < f では正立・虚像・拡大で、像は物体と同じ側にできる。u が f に近いほど実像は遠く、大きくなる。

## 解説
### 式が像の位置をどう決めるか
1/u + 1/v = 1/f を 1/v = 1/f − 1/u と書き直す。物体距離 u が小さくなると 1/u が大きくなり、1/v が小さくなって像距離 v が大きくなる。だから f より遠い物体をレンズに近づけると、実像はレンズから遠ざかる。

### 倍率はなぜ変わるか
倍率は m = −v/u である。u が小さく v が大きくなるので比 v/u が大きくなり、|m| も大きくなる。m の符号は v の符号で決まる。v > 0 なら m < 0 で倒立の実像、v < 0 なら m > 0 で正立の虚像になる。

### u = f という特別な場合
u = f のとき 1/f − 1/u = 0、つまり 1/v = 0 となり v は無限大に近づく。物体を出た光はレンズを通ったあと互いに平行になり、レンズの反対側でも逆向き延長線でも交わらないため、有限の像はできない。ここで v を「非常に大きい有限の数」として扱ってはいけない。

## 確かめ
f = 0.10 m とする。u = 0.20 m で v = 0.20 m、m = −1（実像・倒立・等大）。u = 0.15 m で v = 0.30 m、m = −2（実像・倒立・拡大）。u = 0.05 m で v = −0.10 m、m = 2（虚像・正立・拡大、物体と同じ側）。それぞれ 1/u + 1/v が 1/f に等しいことを確かめよう。

## 発展
発散レンズ（凹レンズ、f < 0）でも式 1/u + 1/v = 1/f は成り立つが、v は常に負で、縮小・正立の虚像しかできない。自分で導いて確かめよう。[単振り子と時間](/ja/labs/pendulum)と比べて、式で変化を表す考え方が共通している点も見てみよう。
