# 微分と接線

f(x) = x² では、P = (x₀, x₀²) と Q = (x₀ + h, (x₀ + h)²) を結ぶ割線の傾きは、h ≠ 0 のとき 2x₀ + h です。h を左右どちらからゼロに近づけても、傾きは 2x₀ に近づきます。これが x₀ での微分係数です。h = 0 で差商そのものは定義されません。極限は近くの値を調べるもので、ゼロで割る操作ではありません。

## 問い
Q を右側または左側から P に近づけると、割線の傾きはどう変わる？

頂点で接線が水平なら、曲線全体も水平なの？

h = 0 で差商が定義されなくても、微分係数が存在するのはなぜ？

## 予想
x₀ = 1 に固定し、h = 1、0.1、−0.1 のときの割線の傾きを予想しよう。正負の間隔から同じ値に近づくだろうか。操作する前に予想を書こう。

## 操作
x₀ = 1 とし、h = 1、0.5、0.1、0.01 を順に入力しよう。割線の傾き、接線の傾き、傾きの差の絶対値を記録し、h = −1、−0.5、−0.1、−0.01 でも繰り返そう。丸い点 P は基点にとどまり、四角い点 Q が放物線上を動く。実線の直線が割線、破線の直線が接線だ。

h = 0 を入力し、表示値のそばの説明を読もう。次に x₀ = 0 として h = 0.1 と −0.1 を比較し、最後に x₀ = −1 で同じ間隔を試そう。「パラメーターを戻す」で x₀ = 1、h = 1 に戻る。この実験は時間に依存せず、再生操作はない。

## 観察
x₀ = 1 では、正の間隔で傾きは 3、2.5、2.1、2.01、負の間隔で 1、1.5、1.9、1.99 となる。接線の傾きは 2 のままだ。傾きの差の絶対値は |h| なので、間隔を半分にすると誤差も半分になる。

頂点 x₀ = 0 では接線が水平になり、x₀ = −1 では傾き −2 で右下がりになる。微分係数は局所的な変化を表し、点の高さや曲線全体の向きではない。パラメーターを変えても縮尺は変わらない。点が近いと重なって見えるため、数値も比べよう。

## 解説
### 差商からどうやって微分係数を求める？
割線は異なる二点を比較する。その傾きは出力の変化量を、符号付きの入力の変化量で割ったものだ。平方を展開すると、h ≠ 0 のとき：

((x₀ + h)² − x₀²) / h = (2x₀h + h²) / h = 2x₀ + h。

h を左右からゼロに近づけると f′(x₀) = 2x₀ を得る。P を通る接線の方程式は y = x₀² + 2x₀(x − x₀) となる。接線は P の近くで曲線を近似するが、曲線全体を表すわけではない。

### なぜ h にゼロを代入してはいけない？
元の差商は 0/0 となり、値が定義されない。h を約分できるのは h がゼロでない場合だけだ。微分係数は近くの定義された差商の極限であり、ゼロ間隔の差商に値を与えるものではない。そのため h = 0 では割線を非表示にし、解析式で求めた接線を残す。

モデルはゼロでない間隔に対して簡約した式を用い、近い数の引き算による桁落ちを避けている。座標は無次元で、表示値は小数点以下三桁に丸められる。ごく小さな間隔は画面や丸めた値では区別できないことがある。極限を示す根拠は式の変形であり、有限回の観察は説明を助けるものだ。他の関数には別の検討が必要で、微分できるとは限らない。

## 確かめ
操作せずに x₀ = −1、h = 0.1 と −0.1 での傾きを予想し、−1.9 と −2.1 になることを確かめよう。どちらも −2 に近づく。x₀ = 0、h = 0.1 では割線の傾きは 0.1、接線の傾きは 0 だ。ほぼ水平な線と完全に水平な線は異なる。

h = 0 で差商は定義されないのに、ここで微分係数が存在する理由を自分の言葉で説明しよう。「ゼロで割る」という説明になったら、ゼロでない間隔での展開式に戻って確認しよう。

## 発展
[二次関数の実験](/ja/labs/function-transform)に戻って放物線の位置や形を変えてみよう。f(x) = a(x − b)² + c の差商を展開し、f′(x₀) = 2a(x₀ − b) を導こう。ここで b は水平移動を表し、本実験の h は入力間の間隔を表す。

紙の上で f(x) = |x| のゼロにおける左右の割線の傾きを比べよう。右からは 1、左からは −1 に近づくため、ゼロでは微分できない。この関数は実験には描かれていない。
