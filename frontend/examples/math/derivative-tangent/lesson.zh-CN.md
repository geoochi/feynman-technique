# 导数与切线

对于 f(x) = x²，P = (x₀, x₀²) 与 Q = (x₀ + h, (x₀ + h)²) 之间的割线斜率在 h ≠ 0 时为 2x₀ + h。当 h 从两侧趋近零，斜率都趋近 2x₀，这就是 x₀ 处的导数。h = 0 时差商本身仍无定义；求极限是在研究附近的值，不是在除以零。

## 问题
Q 从右侧或左侧靠近 P 时，割线斜率怎样变化？

顶点处的切线水平，是否表示整条曲线都是水平的？

为什么 h = 0 时差商无定义，而导数仍然存在？

## 预测
固定 x₀ = 1，预测 h = 1、0.1、−0.1 时的割线斜率。正负间隔会趋向同一个值吗？先写下预测，再调节参数。

## 操作
设 x₀ = 1，依次输入 h = 1、0.5、0.1、0.01，记录割线斜率、切线斜率和斜率差的绝对值。再依次输入 h = −1、−0.5、−0.1、−0.01。圆点 P 固定在基点，方点 Q 沿抛物线移动；实直线为割线，虚直线为切线。

输入 h = 0，阅读读数旁的说明。然后设 x₀ = 0，比较 h = 0.1 与 −0.1；最后设 x₀ = −1，重复相同间隔。“重置参数”恢复 x₀ = 1、h = 1。本实验不随时间变化，没有播放控制。

## 观察
x₀ = 1 时，正间隔对应的斜率依次为 3、2.5、2.1、2.01；负间隔对应 1、1.5、1.9、1.99。切线斜率始终为 2。斜率差的绝对值为 |h|，间隔减半，这个误差也减半。

顶点 x₀ = 0 处切线水平；x₀ = −1 处切线向下倾斜，斜率为 −2。导数描述局部变化，不是点的高度，也不是整条曲线的变化方向。改变参数时图形保持相同比例尺。两点很近时可能看起来重合，需要结合读数观察。

## 解释
### 差商怎样得到导数？
割线比较两个不同的点，斜率等于输出变化量除以带符号的输入变化量。展开平方，在 h ≠ 0 时得到：

((x₀ + h)² − x₀²) / h = (2x₀h + h²) / h = 2x₀ + h。

h 从左右两侧趋近零，得到 f′(x₀) = 2x₀。过 P 的切线方程因此为 y = x₀² + 2x₀(x − x₀)。它近似描述 P 附近的曲线，而非整条曲线。

### 为什么不能直接令 h 等于零？
原差商会变成 0/0，它没有定义。约去 h 的前提是 h 不为零。导数是这些有定义的邻近差商的极限，不能使零间隔的差商也变得有定义。因此 h = 0 时实验隐藏割线，保留解析计算的切线。

模型在非零间隔时使用化简式，避免两个非常接近的数相减导致精度损失。坐标无量纲，读数保留三位小数。极小间隔在屏幕或舍入后可能无法区分。代数推导确立极限，有限次观察只用于展示；其他函数需要分别分析，并非一定可导。

## 验证
先不操作，预测 x₀ = −1、h = 0.1 和 −0.1 时的斜率，再核对结果为 −1.9 和 −2.1，两者趋向 −2。当 x₀ = 0、h = 0.1 时，割线斜率为 0.1，切线斜率为 0：“接近水平”不等于“完全水平”。

用自己的话解释为什么这里 h = 0 时差商无定义，导数却存在。如果解释中出现“除以零”，请回到非零间隔的展开式重新检查。

纸上比较 f(x) = |x| 在零点两侧的割线斜率：它们分别趋向 1 和 −1，因此零点不可导。实验没有绘制这个函数。
