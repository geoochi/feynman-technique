# 定积分与黎曼和

对于 f(x) = x²，曲线在 x = a 到 x = b 之间与 x 轴围成的面积等于 (b³ − a³)/3。黎曼和把区间 [a, b] 分成 n 个宽度为 Δx = (b − a)/n 的子区间，在每个子区间内取一个采样点 xᵢ = a + (i + s)Δx，再把矩形面积 f(xᵢ)Δx 相加。随着 n 增大，这个和逼近精确的定积分；采样位置 s 决定矩形位于单调曲线的上方还是下方。

## 问题
当子区间数 n 不断增大时，小矩形面积之和怎样逼近曲线下的面积？

在 f(x) = x² 递增的区间上，为什么取左端点会使面积偏小？

当区间长度为零时读数显示什么，它表示的是带符号定积分还是几何面积？

## 预测
保持 a = 0、b = 2。在操作之前，预测 n = 1、2、4、8 时的左端点和。它会从下方上升逼近精确值 8/3 ≈ 2.667，还是从上方下降逼近？再预测 s = 0.5 和 s = 1 时误差会怎样变化。

## 操作
设 a = 0、b = 2、n = 8。先取 s = 0，记录黎曼和、精确值与误差。把 s 调到 0.5，再调到 1，观察误差符号的变化。保持 s = 0，把 n 依次调到 4、8、16、40，记录误差怎样缩小。

再把 a 与 b 设为相等，例如 a = b = 1：每个矩形宽度为零，和为 0。试一个负区间，如 a = −2、b = 0，再反过来设成 a = 2、b = 0。“重置参数”恢复 a = 0、b = 2、n = 8、s = 0。图形使用固定比例尺，参数只会让矩形移动而不会缩放整个画面；本实验没有时钟或播放。

## 观察
在 [0, 2] 上取 n = 8，左端点和为 2.1875，小于精确值 8/3 ≈ 2.6667，误差为负；右端点和为 3.1875，大于精确值，误差为正；中点和为 2.65625，比两端都更接近。

n 加倍时，左端或右端的误差大致减半，而中点误差约减为四分之一。n = 40 时左端误差已经小于 0.05。当 a = b 时每一项都为零，读数提示区间长度为零；交换端点会让和与精确值同时变号。

## 解释
### 面积之和为什么能逼近定积分？
每个矩形的宽是 Δx、高是 f(xᵢ)。精确的定积分就是这些和在 Δx → 0（即 n = (b − a)/Δx 无限增大）时的极限：

∫ₐᵇ f(x) dx = lim (n → ∞) Σ f(xᵢ) Δx。

对 f(x) = x²，原函数是 F(x) = x³/3，由微积分基本定理得到精确值 (b³ − a³)/3。对 [0, 2] 就是 8/3 ≈ 2.6667。

### 每个子区间该取哪个点？
若 f 在子区间上递增，左端点给出最小的高、右端点给出最大的高，所以在 [0, 2] 上左端和位于精确值下方、右端和位于上方，两者把它夹在中间。取中点可以把误差从 Δx 阶降到 Δx² 阶，这正是 n 加倍时中点误差减为四分之一、而两端误差只减半的原因。s = 0、0.5、1 只是定义中“在子区间内取点”的三种选择；极限与子区间内具体取哪个点无关。

### 带符号定积分还是几何面积？
读数显示的是带符号定积分 ∫ₐᵇ f(x) dx。由于 f(x) = x² 不会取负值，带符号定积分与曲线下的几何面积相等，所以本页两者数值相同。若函数在 x 轴下方出现，带符号定积分会把那部分计为负，而几何面积会把它计为正，两者就不再相等。交换端点，例如 a = 2、b = 0，会让和与精确值同时变号。

## 验证
先不操作，预测 [0, 2] 上 n = 16、s = 0 时的误差，再核对它约为 −0.24。预测同样 n 下右端和的误差，并确认约为 +0.24。当 a = b = 1 时，核对黎曼和、精确值与误差都恰好为 0。

用自己的话解释：中点法为什么比左右端点法收敛更快？如果 f 取到负值，带符号定积分为什么会与几何面积不同？
