# 曲線下の面積とリーマン和

f(x) = x² では、x = a から x = b までの曲線と x 軸が囲む面積は (b³ − a³)/3 です。リーマン和は区間 [a, b] を幅 Δx = (b − a)/n の n 個の小区間に分け、各小区間で一点 xᵢ = a + (i + s)Δx を標本にとり、長方形の面積 f(xᵢ)Δx を足し合わせます。n を大きくすると和は正確な定積分に近づき、標本位置 s が長方形を単調な曲線の上側に置くか下側に置くかを決めます。

## 問い
小区間の数 n を大きくすると、小さな長方形の面積の和はどうやって曲線下の面積に近づく？

f(x) = x² が増加する区間で、左端をとると面積を過小評価するのはなぜ？

区間の長さがゼロのとき表示は何を示し、それは符号付き定積分と図形の面積のどちら？

## 予想
a = 0、b = 2 のままにする。操作する前に n = 1、2、4、8 での左端の和を予想しよう。和は正確な値 8/3 ≈ 2.667 に下から近づくか、上から近づくか。次に s = 0.5 と s = 1 で誤差がどう変わるかも予想しよう。

## 操作
a = 0、b = 2、n = 8 とする。まず s = 0 にして、リーマン和・正確な値・誤差を記録しよう。s を 0.5、次に 1 へ動かし、誤差の符号が変わるのを見よう。s = 0 のまま n を 4、8、16、40 と増やし、誤差がどう小さくなるか記録しよう。

次に a と b を等しくする。たとえば a = b = 1 では、どの長方形も幅が 0 で和は 0 になる。a = −2、b = 0 のような負の区間を試し、さらに a = 2、b = 0 と入れ替えてみよう。「パラメーターを戻す」で a = 0、b = 2、n = 8、s = 0 に戻る。図は固定スケールなので、パラメーターを変えても長方形が動くだけで図全体は拡大縮小しない。この実験に時計や再生はない。

## 観察
[0, 2] で n = 8 のとき、左端の和は 2.1875 で正確な値 8/3 ≈ 2.6667 より小さく、誤差は負になる。右端の和は 3.1875 で正確な値より大きく、誤差は正になる。中点の和は 2.65625 で、両端よりずっと近い。

n を 2 倍にすると、左端・右端の誤差はほぼ半分に、中点の誤差は約 4 分の 1 になる。n = 40 では左端の誤差はすでに 0.05 未満だ。a = b のときは各項が消えて和は 0 になり、表示は区間の長さがゼロであることを示す。端点を入れ替えると和と正確な値の符号が同時に反転する。

## 解説
### 和はなぜ定積分に近づく？
各長方形の幅は Δx、高さは f(xᵢ) です。正確な定積分は、Δx → 0（つまり n = (b − a)/Δx が限りなく大きくなる）ときのこれらの和の極限です：

∫ₐᵇ f(x) dx = lim (n → ∞) Σ f(xᵢ) Δx。

f(x) = x² の原始関数は F(x) = x³/3 なので、微積分学の基本定理から正確な値 (b³ − a³)/3 が得られます。[0, 2] では 8/3 ≈ 2.6667 です。

### 各小区間でどの点をとるべき？
小区間で f が増加するなら、左端は最小の高さ、右端は最大の高さを与えます。そのため [0, 2] では左端の和は正確な値より下、右端の和は上にあり、両者が正確な値を挟みます。中点をとると誤差は Δx の次数から Δx² の次数へ下がります。これが、n を 2 倍にしたとき中点の誤差は 4 分の 1 になり、両端は半分にしかならない理由です。s = 0、0.5、1 は「小区間内で一点を選ぶ」方法の一つにすぎず、極限は選び方によらず同じです。

### 符号付き定積分か図形の面積か？
表示は符号付き定積分 ∫ₐᵇ f(x) dx です。f(x) = x² は負にならないので、符号付き定積分は曲線下の図形の面積に等しく、このページでは両者が一致します。関数が x 軸の下に出る場合、符号付き定積分はその部分を負として引き、図形の面積は正として数えるため、両者は異なります。端点を入れ替えると（例：a = 2、b = 0）、和と正確な値の符号が同時に反転します。

## 確かめ
操作せずに、[0, 2] の n = 16、s = 0 での誤差を予想し、約 −0.24 になることを確かめよう。同じ n での右端の和の誤差も予想し、約 +0.24 であることを確かめよう。a = b = 1 では、リーマン和・正確な値・誤差がすべて正確に 0 になることを確認しよう。

中点法が左右の端の方法より速く収束する理由と、f が負の値をとる場合に符号付き定積分が図形の面積と異なる理由を、自分の言葉で説明しよう。
