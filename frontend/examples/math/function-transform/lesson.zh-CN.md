# 二次函数

## 问题
只改变水平平移参数 h，抛物线的顶点会怎样移动？

纵向伸缩参数 a 的正负和绝对值，分别如何影响开口方向与宽窄？

怎样调整 a、h、k，让抛物线顶点位于 (2, −1) 且开口向下？

## 预测
先不动滑块：把 h 从 0 改成 2，你认为顶点会向左还是向右移动？把自己的判断与接下来的结果比较。

## 操作
保持 a = 1、k = 0，只改变 h。再将 h 归零，分别调整 k 和 a。蓝色虚线始终表示 y = x²，琥珀色实线表示当前函数。

## 观察
h 控制顶点的左右位置，k 控制上下位置。a 的绝对值越大，抛物线越窄；a 为负时开口向下。a = 0 时，图像退化为水平直线。

## 解释
函数 y = a(x − h)² + k 的顶点在 (h, k)，但 a = 0 时不再有唯一顶点。括号里的减号要求 x = h 才能令平方项为零。水平平移影响输入，竖直平移影响输出。

## 验证
试着把顶点移到 (2, −1)，同时让开口向下。目标参数是 h = 2、k = −1、a < 0。检查几组对称点，它们的函数值是否相同？

## 延伸
把二次函数换成绝对值函数，这三种变换还成立吗？对任意函数 f，y = a f(x − h) + k 都有类似的平移与纵向伸缩规律。
