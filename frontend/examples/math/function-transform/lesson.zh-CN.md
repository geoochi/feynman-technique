# 二次函数

在 y = a(x − h)² + k 中，a ≠ 0 时抛物线的顶点为 (h, k)：h 决定水平位置，k 决定竖直位置。a 为正时开口向上，为负时开口向下；|a| 越大，抛物线越窄。a = 0 时函数退化为水平直线 y = k，没有唯一顶点。逐一调整参数，可以分别观察这些变化。

## 问题
只改变水平平移参数 h，抛物线的顶点会怎样移动？

纵向伸缩参数 a 的正负和绝对值，分别如何影响开口方向与宽窄？

怎样调整 a、h、k，让抛物线顶点位于 (2, −1) 且开口向下？

## 预测
先不动滑块：把 h 从 0 改成 2，你认为顶点会向左还是向右移动？把自己的判断与接下来的结果比较。

## 操作
保持 a = 1、k = 0，只改变 h。再将 h 归零，分别调整 k 和 a。蓝色虚线始终表示 y = x²，琥珀色实线表示当前函数。

## 观察
h 控制顶点的左右位置，k 控制上下位置。a 的绝对值越大，抛物线越窄；a 为负时开口向下。a = 0 时，图像退化为水平直线。

## 解释
### 为什么 h 为正时图像向右移动？
a ≠ 0 时，y = a(x − h)² + k 的平方项在 x = h 处为零，顶点因此为 (h, k)。h 从 0 变成 2，顶点就移到右侧的 x = 2。更一般地，要得到原来 x² 的同一个输出，需要把输入增大 h。水平平移影响输入，竖直平移影响输出。

### a 怎样改变开口与宽窄？
在距 x = h 相同的非零水平距离处，乘以 a 会缩放图像距 y = k 的竖直距离。因此在相同的顶点竖直距离处，|a| 越大，抛物线越窄。a 为负时图像向下翻转。a = 0 时所有输入都得到 y = k，这是没有唯一顶点的常函数，不再是抛物线。

## 验证
试着把顶点移到 (2, −1)，同时让开口向下。目标参数是 h = 2、k = −1、a < 0。检查几组对称点，它们的函数值是否相同？

## 延伸
把二次函数换成绝对值函数，这三种变换还成立吗？对任意函数 f，y = a f(x − h) + k 都有类似的平移与纵向伸缩规律。
