# 二次関数

## 問い
水平移動のパラメーター h だけを変えると、放物線の頂点はどう動く？

a の符号と絶対値は、放物線の開く向きと幅にそれぞれどう影響する？

頂点を (2, −1) に置き、下向きに開く放物線にするには、a・h・k をどう設定する？

## 予想
スライダーを動かす前に、h を 0 から 2 に変えると頂点が左右どちらに動くか予想しよう。予想と実際の結果を比べてみよう。

## 操作
a = 1、k = 0 のまま h だけを変える。その後 h を 0 に戻し、k と a を別々に変える。青い破線は常に y = x²、琥珀色の実線は現在の関数を示す。

## 観察
h は頂点の左右の位置、k は上下の位置を決める。a の絶対値が大きいほど放物線は狭くなる。a が負なら下向きに開く。a = 0 のとき、グラフは水平な直線になる。

## 解説
y = a(x − h)² + k の頂点は (h, k) にある。ただし a = 0 では頂点は一意に決まらない。括弧内のマイナス記号は、x = h のとき平方の項が 0 になることを示す。水平移動は入力を、垂直移動は出力を変える。

## 確かめ
頂点を (2, −1) に移し、下向きに開くようにしよう。条件は h = 2、k = −1、a < 0。x = h に関して対称な点の関数値は等しくなる？

## 発展
絶対値関数でも同じ変換は使える？任意の関数 f に対して、y = a f(x − h) + k には同様の平行移動と縦方向の拡大・縮小の規則がある。
